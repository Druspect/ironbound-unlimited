# Graphics origin library

Real-world references for measuring wheel arrangements, driver scale, running gear, tenders, carriage doors, windows, rooflines, and underframes. These photographs are reference inputs and are not shipped by the game.

`manifest.json` records identity, source, proxy status, and reuse restrictions. Ironbound No. 1 and The Flyer are fictional; their files are explicitly labelled period proxies. The holiday locomotive is grounded in the real Pere Marquette No. 1225 rather than film artwork.
